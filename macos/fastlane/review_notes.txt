Thank you for reviewing M1K3.

NO ACCOUNT REQUIRED — just launch and use it.

FIRST LAUNCH:
  Mac: on most Macs, uses Apple Intelligence (instant, no download).
  iPhone/iPad: downloads a local AI model (~3 GB on 8 GB devices). After setup, fully offline.
  Without Apple Intelligence on any platform, downloads a local model (~630 MB–3 GB).
  Lil (the downloaded 4B brain) accepts image attachments: the paperclip in chat takes a photo or screenshot, read on-device.

OUTBOUND (network.client): model download + web search (ON by default so answers can be current; one switch turns it off: Settings > Privacy > Web search (DuckDuckGo)). No analytics, tracking, or telemetry.

INBOUND (network.server): two features, both OFF by default in Settings > Privacy:
  1. MCP server — loopback only (127.0.0.1:4242), needs an access token, lets AI coding agents call M1K3's tools. Verify: Settings > Privacy > MCP server > Access token > Copy; then run /Applications/M1K3.app/Contents/Helpers/m1k3 login (paste it), then .../m1k3 status
  2. Brain at Home — LAN service for QR-paired iPhone/iPad only. TLS-PSK, private interfaces. Verify: dns-sd -B _m1k3._tcp
The helper (Contents/Helpers/m1k3) is a client only; no server entitlement.

CONTENT CONTROLS (DeclaredAgeRange): uses Apple's Declared Age Range API (gates 13/16/18). Under 16: web tools removed from the agent palette (code gate). All minors: age-appropriate tone. Declining = full capability. Only a coarse band enum is persisted.
  Mac: Settings > Privacy tab > Content Controls > "Set up"
  iPhone/iPad: Settings > Content Controls > "Set up"

CALENDAR + LOCATION: optional context senses, OFF by default, so no alert at launch (expected). The macOS alert appears the moment you switch one on: Settings > Privacy > Context > Calendar (or Location). Declining turns the switch back off. Then ask "What's on my calendar today?" (or "Where am I?"). On-device only; never stored or sent.

CALL RECORDING (system audio): user-started, consent-affirmed. Captures the Mac's audio output (the other side of a call) + the mic, transcribed on-device (WhisperKit). Audio only, never screen content. The audio and transcript stay on the Mac. Recording deleted after transcription; transcript encrypted, deletable. Policy: https://m1k3.app/privacy#call-recording

MICROPHONE: on-device speech-to-text. Never transmitted.
FILES: user-selected notes/PDFs only. Processed locally.

HOW TO TEST:
  1. Finish onboarding + model download
  2. Chat, then voice mode
  3. Drag in a note/PDF and ask about it
  4. Memories > "forget" an item
  5. Content Controls:
     Mac: Settings > Privacy tab > Content Controls > "Set up"
     iPhone/iPad: Settings > Content Controls > "Set up"
