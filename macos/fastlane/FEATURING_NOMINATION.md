# App Store featuring nomination — M1K3 1.1 (paste-ready)

Submit in **App Store Connect → M1K3 → Featuring Nominations → New** (role:
Account Holder / Admin / App Manager / Marketing). Apple asks for three
weeks' lead; a launch nomination is still the right type at launch — the
editorial window for a new release is weeks, not months. Every field below
is within its cap (name 60 · description 1,000 · helpful details 500) and
every claim is true of build 519, the 1.1 candidate for Mac, iPhone and iPad. The 1.1
release is the iPhone and iPad debut (the Mac has had 1.0 since 11 Oct), so a launch
nomination still fits. If the 11 Oct Mac draft is still unsubmitted, rewrite it with this.

**Nomination name** (≤60)
> M1K3 — a local, offline AI agent for Mac, iPhone and iPad

**Nomination type** → **App Launch** (cannot be changed after submission)

**Description** (≤1,000)
> M1K3 is a local, offline AI agent for Mac, iPhone and iPad from a solo Irish
> developer. On-device brains: Apple's Foundation Models first, then Qwen and
> Gemma on MLX, with a neural voice, a 3D companion, and your notes and PDFs as
> memory you can see, search and delete. No account, no analytics:
> the privacy label reads Data Not Collected. Conversations stay on the device
> by default; web search (on by default) and an opt-in Private Cloud Compute
> brain are each one switch.
>
> Built for the platform: SwiftUI, Liquid Glass, Core Spotlight, a menu-bar
> companion, a notch caption that follows the voice, VoiceOver
> throughout. Brain at Home lends an iPhone the Mac's brain over the local
> network, encrypted, no relay. It is also an MCP server, so coding agents
> can use it as a private knowledge store.
>
> For Halloween, 24 Oct to 1 Nov, the Phosphor Fox glows pumpkin orange and
> greets you in costume. Universal purchase, free, eight languages,
> source-available on GitHub.

## Editorial angles this fits (for the description's emphasis, not to paste)

- **Golden Gate, now in your pocket** — the iPhone and iPad debut, built on
  the frameworks the release headlines: Foundation Models, Liquid Glass.
- **Seasonal** — the Halloween look (24 Oct – 1 Nov) and its event card.
- **"Made for Mac"** — menu bar, notch, Spotlight, sandbox.
- **Privacy** — Data Not Collected on a chatbot is rare; it is the story.
- **Accessibility spotlight** — built by a dyslexic developer, reading mode
  in the product.
- **Indie / solo-developer story** — the same card Cartogram played.

## What is NOT claimed (keep it that way)

No download numbers (none are public yet), no visionOS, no "open source"
(FSL-1.1 — say source-available), no third-party product names beyond the
models and frameworks it is built on, and no "no cloud" or "no network"
absolutes: web search is on by default, and Private Cloud Compute is an
opt-in brain.
