1.6 新内容

• 应季换装。从 12 月 2 日起，圣诞节和新年期间我会亮起糖果红与金色，全年还会为农历新年、斋月和开斋节、圣帕特里克节、诺鲁孜节换装。Settings 里一个开关就能关掉这些造型。
• 聊天旁边的代码。让我做一个小网页，它会在聊天旁边打开，可以直接看，而不只是读。点击任意代码块上的“Open”，就能看那一个。网页是封闭的：不运行任何脚本，也不从互联网加载任何内容。网页可以作为 .html 文件分享或保存。
• 用 M1K3 打开。在 Finder 里右键点按文本、代码或 JSON 文件，选择“打开方式 ▸ M1K3”，或者在 Dock 里把文件拖到我身上。它会落进消息栏，随时可以提问，绝不会自己发送。
• 如果我回答时有文件送到，我会告诉你它在等着，等我答完再放进消息栏。

万一你错过了（1.4 和 1.5）

• 我说你的语言：应用除了英语，还有德语、法语、西班牙语和巴西葡萄牙语，我会用你书写的语言回答。
• 读一段文本。把 .txt、.md、.csv 或 .log 文件拖进聊天，然后提问。文件不会发往别处。
• 遇到多步骤的问题，Lil 会分成简短的步骤来解；当一个问题需要认真思考，我会用一句平实的话说明。
• 在语音模式下，我引用的网页会在我旁边打开，引用的内容会高亮显示。
• 我说日期、金额和数字像人一样。让我说得更直白一点，我就照做。
• 每个控件都有供 VoiceOver 和语音控制使用的名称。
• Local API：在 Settings > Server 里打开，任何支持 OpenAI API 的应用都能使用你已加载的大脑，仅限这台 Mac。默认关闭，并且有自己的密钥。

初次接触 M1K3？我能做什么

• 三个大脑：Mini（即开即用，基于 Apple Intelligence）、Lil（4B，能看图片）和 Big（12B）。选最适合你 Mac 的那个。
• 和我说话：设备端语音识别，加上自然的神经语音。
• 带上你自己的知识：拖入笔记、PDF 和文本文件，我会在你的 Mac 上依据它们回答。
• 我会记住对你重要的事，记在一份你可以查看、搜索和删除的记忆里。
• 通话记忆：经你同意，我会在你的 Mac 上转录并总结通话。保存的通话记录已加密。
• Brain at Home：通过你自己的 Wi‑Fi 配对 iPhone 或 iPad，窝在沙发上也能用 Mac 的大脑。
• 你的编程智能体可以通过本地 MCP 服务器和 m1k3 命令行工具，使用我的知识和声音。
• 你的其他应用可以通过 Local API 使用我的大脑，仅限这台 Mac。
• Siri 和快捷指令可以向我提问，也能往我的知识里添加内容。
• Private Cloud Compute，想用才用：默认关闭。选用时，我会在第一次询问你。

其余一切都在你的 Mac 上运行。无需账户，无遥测。网络只用于模型下载、网页搜索和可选的私有云。Settings > Brains & downloads 列出每一项下载；网页搜索和私有云是 Settings > Privacy 里的开关，把私有云借给其他应用则是 Settings > Server 里单独的开关。
