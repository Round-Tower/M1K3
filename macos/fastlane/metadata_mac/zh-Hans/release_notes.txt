1.5 新内容

• 我说你的语言。除了英语，应用现在还有德语、法语、西班牙语和巴西葡萄牙语，并跟随你 Mac 的语言。无论是哪个大脑在回答，我都用你书写的语言回答。语音模式下，我目前仍然只听英语；用其他语言的回答，由会说那种语言的声音来朗读。部分隐私说明在母语人士审核之前仍保持英文。
• 读一段文本。把 .txt、.md、.csv 或 .log 文件拖进聊天，然后提问（“保修什么时候到期？”）。回答只依据这个文件，文件也不会发往别处。“Ask more”会继续围绕同一份文本提问；“Keep this”会把它保存到你的文档。
• Lil 会算清楚。遇到多步骤的问题、算术题或谜题，Lil 现在会先分成几个简短的步骤思考，再给出回答：答对的更多，而且仍然是那个快速的大脑。
• 我思考时会告诉你。当一个问题需要认真思考，我会用一句平实的话说明，而不是只让你对着转圈的加载图标干等。
• 看我引用了什么。在语音模式下，当我引用某个网页时，点击标签，或者说“show me that”，网页就会在我旁边打开，引用的内容会高亮显示。“Scroll down”“go back”和“close it”也同样可用。网页绝不会自己打开。
• 我说数字像人一样：日期、时间、金额、分数、版本号，还有“Henry VIII”。而且“I'm”“I'll”和“I've”现在听起来也对了。
• 说话更直白。反派是外观，不是声音。让我说得更直白一点，我就照做。
• 无障碍：每个控件都有供 VoiceOver 和语音控制使用的名称，对比度也经过测量。
• 干净的开始：新聊天打开时不再带建议问题。
• 已修复：遇到某些表情符号时，回答可能会中断。
• 修复隐私问题：附件中的文本可能进入网页搜索，或在你选用时进入 Apple 的 Private Cloud。在 iPhone 和 iPad 上，Content Controls 未能为年轻用户关闭网页搜索或调整 Mike 的语气。两者均已修复。

初次接触 M1K3？我能做什么

• 三个大脑：Mini（即开即用，基于 Apple Intelligence）、Lil（4B，能看图片）和 Big（12B）。选最适合你 Mac 的那个。
• 和我说话：设备端语音识别，加上自然的神经语音。
• 带上你自己的知识：拖入笔记、PDF 和文本文件，我会在你的 Mac 上依据它们回答。
• 我会记住对你重要的事，记在一份你可以查看、搜索和删除的记忆里。
• 通话记忆：经你同意，我会在你的 Mac 上转录并总结通话。保存的通话记录已加密。
• Brain at Home：通过你自己的 Wi‑Fi 配对 iPhone 或 iPad，窝在沙发上也能用 Mac 的大脑。
• 你的编程智能体可以通过本地 MCP 服务器和 m1k3 命令行工具，使用我的知识和声音。
• 你的其他应用可以通过 Local API 使用我的大脑，仅限这台 Mac。
• Siri 和快捷指令可以向我提问，也能往我的知识里添加内容。
• Private Cloud Compute，想用才用：默认关闭。选用时，我会在第一次询问你。

其余一切都在你的 Mac 上运行。无需账户，无遥测。网络只用于模型下载、网页搜索和可选的私有云。Settings > Brains & downloads 列出每一项下载；网页搜索和私有云是 Settings > Privacy 里的开关，把私有云借给其他应用则是 Settings > Server 里单独的开关。
