NEU IN 1.4

• Ein lokaler Server für deine anderen Apps. Schalte die Local API unter Settings > Server ein, und jedes Werkzeug, das die OpenAI API spricht (ein Editor, ein Skript, eine Chat-App), kann das Hirn nutzen, das du geladen hast. Sie lauscht nur auf diesem Mac, ist standardmäßig aus und hat einen eigenen Schlüssel. Du bist zuerst dran: Ein Aufruf wartet, solange du chattest, und endet, sobald du eine neue Runde beginnst.
• Apples private Cloud für deine anderen Apps, wenn du willst. Schalte „Also offer Private Cloud Compute“ ein, und ein zweites Modell, cloud-m1k3, antwortet aus Apples Private Cloud Compute: ein größeres Hirn für die Jobs, die eins brauchen. Deine Coding-Agenten bekommen dasselbe über MCP, mit einem eigenen Schalter. Beide sind standardmäßig aus. Es geht nur hinaus, was die App sendet; ich füge nichts von dir hinzu, und Settings zählt jeden Aufruf.
• Settings > Server. Der MCP-Server für deine Coding-Agenten und die neue Local API teilen sich einen Bereich, jeweils mit eigenem Schalter und eigenem Schlüssel.
• Mini beantwortet die Frage. Mini hatte sich angewöhnt, ganz normale Coding-Fragen mit einem Satz darüber zu beantworten, dass es seine Verdrahtung nicht preisgibt. Das ist behoben.

NEU BEI M1K3? DAS MACHE ICH

• Drei Hirne: Mini (sofort, über Apple Intelligence), Lil (4B, liest Bilder) und Big (12B). Wähl das Passende für deinen Mac.
• Sprich mit mir: Spracherkennung auf dem Gerät und eine natürliche neuronale Stimme.
• Bring dein eigenes Wissen mit: Zieh Notizen und PDFs hinein, und ich antworte auf ihrer Grundlage, auf deinem Mac.
• Ich merke mir, was dir wichtig ist, in einem Gedächtnis, das du sehen, durchsuchen und löschen kannst.
• Anruf-Gedächtnis: Mit deiner Zustimmung transkribiere ich Anrufe und fasse sie zusammen, verschlüsselt auf deinem Mac.
• Brain at Home: Kopple dein iPhone oder iPad über dein eigenes WLAN und nutze das Hirn deines Macs vom Sofa aus.
• Deine Coding-Agenten können mein Wissen und meine Stimme nutzen, über einen lokalen MCP-Server und das Kommandozeilen-Tool m1k3.
• Deine anderen Apps können mein Hirn über die Local API nutzen, nur auf diesem Mac.
• Siri und Kurzbefehle können mir Fragen stellen und mein Wissen ergänzen.
• Private Cloud Compute, wenn du willst: standardmäßig aus, jede Nachricht einzeln, mit deiner Zustimmung.

Alles andere läuft auf deinem Mac. Kein Konto, keine Telemetrie. Das Netzwerk nutze ich für Modell-Downloads, die Websuche und die optionale Private Cloud. Settings > Brains & downloads nennt jeden Download; Websuche und Private Cloud sind Schalter unter Settings > Privacy, und die Private Cloud an andere Apps zu verleihen ist ein eigener Schalter unter Settings > Server.
