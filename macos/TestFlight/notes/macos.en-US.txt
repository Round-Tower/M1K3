Thanks for testing M1K3 1.5.0 on the Mac.

New in this build, please try:
• Read a text: drop a .txt, .md, .csv or .log file on the chat and ask a question about it ("when does the warranty end?"). The answer should start in a few seconds and stick to the file. Send the file with no words and you should get the gist of the whole text
• Ask more: under a read's answer, tap Ask more. Every message you send then asks about the same text, until you tap the ✕ or switch to another chat
• Keep this: under a read's answer, tap Keep this. A banner should say it was kept in Documents, and searching your documents should find it. A read is never kept unless you tap it. A very long file (a big log) should say it kept the first 100,000 characters
• A link in a read's answer should show as plain code and do nothing when clicked, with no link chip beside it
• These should stay ordinary chat turns, not reads: a .swift or other code file, "translate this" or "write a reply to this" with a file, and any file while Brain at Home or Private Cloud Compute is answering
• Stop a read while it is answering: it should say "Stopped before an answer.", and Keep this should still work
• Listen for "I'm", "I'll", "I've" and "I'd" in spoken answers (voice mode, or Speak on an answer). They should sound right now. So should names such as Abuja, Alzheimer's and iOS
• Accessibility: with VoiceOver on, ask a question, read the answer, and open Memories, Documents and Settings. Every button should say what it does. Tell us about anything VoiceOver reads as just "button"
• With Voice Control on, say "Show names": the names should match what you see on the message field, the memory search, the sidebar and the toolbar
• Try light and dark appearance, Reduce Motion (the avatar and voice mode) and the largest reading size. Tell us about anything hard to read or that moves when it shouldn't

And the basics:
• Chat, then voice mode, a few turns in a row
• Drop a PDF onto the chat and ask about it
• Brain at Home from your iPhone or iPad

A read happens on this Mac: the file goes nowhere else, and it is stored with that chat, so deleting the chat deletes it. The network is used for brain downloads and web search, which is on by default; the switch beside the brain switcher turns it off. Flag anything that looks like it left your Mac when it shouldn't have: Settings → "Report an issue…" attaches a privacy-scrubbed diagnostic.
