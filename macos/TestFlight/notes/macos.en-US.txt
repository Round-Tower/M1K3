Thanks for testing M1K3 1.5.0 on the Mac.

First, this build's privacy fixes. In one chat, please check:
• Files stay off the web: attach a .json or code file, ask "convert this to YAML", then "search the web for today's news". Mike should say the web is off in a chat with a file. In a new chat the same words should search, with sources
• Sharing a chat: pick Private Cloud Compute, send "thanks", turn on "Also send this conversation" and look at what it sends: no file text, and no answer made after the file
• No file memories: that file should not appear in Memories
• Code is not read aloud: ask for some code with Speak answers on. Mike says "I've put that on screen."

Also new in 1.5, please try:
• Your language: in System Settings > General > Language & Region, put German, French, Spanish or Portuguese (Brazil) first, then relaunch M1K3. The app should be in that language. Tell us about any English left on screen (a few privacy notes stay in English on purpose until a native speaker has read them) and any wording that reads oddly
• Write to Mike in another language: he should reply in it, on Mini, Lil and Big
• Voice mode in German or Spanish: ask Mike to answer in that language. The answer should be read by a voice that speaks it, not an English voice reading German. Voice still listens in English
• Lil and a puzzle: on Lil, ask "A bat and a ball cost 1.10 in total. The bat costs 1.00 more than the ball. How much is the ball?" Lil should work it out in a few short numbered steps, then answer, in about ten seconds
• Thinking out loud: Settings > Reasoning > Always think, then ask Lil something hard. A plain line such as "Let me think this one through." should show under Thinking… and go when the answer starts. In voice mode it should only be said aloud if the quiet runs past a few seconds. Tell us whether it helps or feels like noise
• Plainer talk: ask Mike to talk plainer. He should, and stay that way for the rest of the chat
• A new chat should open with no suggested questions
• Ask for an answer with a few emoji in it, such as hearts and ticks: it should finish, not stop at an emoji
• If an answer fails, M1K3 now says so instead of going quiet. If M1K3 ever closes unexpectedly, the report it offers next launch now says what the brain ran into: please send it

Still worth a look:
• Read a text: drop a .txt, .md, .csv or .log file on the chat and ask about it. Ask more and Keep this under the answer
• Voice mode, ask something that needs the web. When Mike quotes a source, click the chip or say "show me that": the page opens beside the avatar. A page should never open by itself
• Spoken numbers ("£5", "10:30", "Henry VIII") and "I'm" should sound the way you'd say them
• VoiceOver and Voice Control: tell us about anything read as just "button"

And the basics:
• Chat, then voice mode, a few turns in a row
• Drop a PDF onto the chat and ask about it
• Brain at Home from your iPhone or iPad

A read happens on this Mac: the file goes nowhere else, and it is stored with that chat, so deleting the chat deletes it. The network is used for brain downloads and web search, which is on by default; the switch beside the brain switcher turns it off. Flag anything that looks like it left your Mac when it shouldn't have: Settings → "Report an issue…" attaches a privacy-scrubbed diagnostic.
