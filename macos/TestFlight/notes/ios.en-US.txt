Thanks for testing M1K3 1.5.0 on iPhone and iPad.

New in this build, please try:
• Read a text: attach a .txt, .md, .csv or .log file from Files and ask a question about it ("when does the warranty end?"). The answer should stick to the file and come from your device: try it in Airplane Mode. Send the file with no words and you should get the gist of the whole text
• How long a long file takes before the first words appear, with Lil and with Mini. Tell us the seconds; we have not timed it on a phone yet
• Ask more: under a read's answer, tap Ask more. Every message then asks about the same text, until you tap the ✕ or switch to another chat
• Keep this: under a read's answer, tap Keep this. A banner should say it was kept in Documents. A read is never kept unless you tap it
• A link in a read's answer should show as plain code and do nothing when tapped
• These should stay ordinary chat turns, not reads: a code file, "translate this" with a file, and any file while Brain at Home is answering
• Stop a read while it is answering: it should say "Stopped before an answer.", and Keep this should still work
• Listen for "I'm", "I'll", "I've" and "I'd" in spoken answers. They should sound right now. So should names such as Abuja, Alzheimer's and iOS
• Accessibility: with VoiceOver on, ask a question, read the answer, and open Memories, Documents and Settings. In Documents, each row should read its title then its date, and swipe to delete should still work
• With Voice Control on, say "Show names": the names should match what you see
• Try the largest text sizes (Settings > Accessibility > Display & Text Size > Larger Text): tell us about anything cut off or overlapping. Dates and small print are a size larger than before; on a small phone, tell us if anything no longer fits
• Try light and dark appearance and Reduce Motion (the avatar and voice mode). Tell us about anything hard to read or that moves when it shouldn't

And the basics:
• Voice mode, a few turns in a row
• Airplane mode: chat should keep working on the device
• Brain at Home with M1K3 on your Mac

A read happens on your device: the file goes nowhere else, and it is stored with that chat, so deleting the chat deletes it. The network is used for brain downloads and web search, which is on by default. Send feedback straight from TestFlight; a screenshot of anything odd helps most.
