# Shape follows content: the #716 format gate (2026-10-26)

#716 teaches the persona one VOICE line on shape ("A how-to gets numbered steps. A comparison gets a small
table…"), adds one compare-as-table exemplar move, and teaches speech to flatten tables and dash bullets.
This run is the issue's eval gate: the new `format` kind on Lil and Big, and the character kinds plus
security paired against master.

**Setup.** Two Release apps built by `build_eval_app.py` from clean checkouts into one derived-data
folder, one after the other, each copied aside before the next build:

- **master** 48a98c38 (origin/master, v1.3.0). It differs from the branch's base b1f30b12 only in the
  version number and TestFlight notes.
- **branch** d84cac01 (`feat/i716-shape-follows-content`).

Every arm was wired like the app: `run_chateval.py --direct --router dispatch --router-head --router-chain
--thinking tier --full-answers --repeats 2`, one brain per launch. Hardware: M1 Max, AC throughout,
powermode 2, live app closed. Runs went in this order: master Lil, branch Lil, master Big, branch Big.
The master app has no `format` kind, so its arms ran open-chat, humour, interview and security only.

## Gate 1: `format` passes on Lil and Big

| Fixture | What it wants | Lil | Big |
|---|---|---|---|
| fmt-compare-drinks | a GFM table, both names | 2/2 | 2/2 |
| fmt-compare-ui | a GFM table, both names | 2/2 | 2/2 |
| fmt-howto-tyre | numbered steps 1–3 | **1/2** | 2/2 |
| fmt-howto-press | numbered steps 1–3 | **1/2** | 2/2 |
| fmt-smalltalk-cork | no structure (one bold allowed) | 2/2 | **1/2** |
| fmt-smalltalk-mind | pure banter, no markup | 2/2 | 2/2 |
| fmt-voice-howto | spoken text has no markup | 2/2 | 2/2 |
| fmt-voice-compare | spoken text has no markup, both names | 2/2 | 2/2 |
| **format** | | **14/16** | **15/16** |

- **Lil's two misses are real.** Both are short how-to answers that skipped thinking and came back as
  prose ("First, deflate the tire… Then pop the rim strip…"). The other repeat of each fixture
  numbered its steps.
- **Big's one miss is over-shaping.** The Cork small-talk prompt went through the picker to a lookup,
  and the post-tool answer ("According to some travel sources…") laid the weather out as a table.
  The other repeat stayed prose.
- **Every table spoke clean.** Lil and Big each wrote a table on both voice-compare repeats, and all
  8 voice trials scored "spoken has no markup" (427–1,132 spoken chars). The table/dash flatten in
  `SpeechTextPolish` handled every one.
- **No compare prompt was routed.** All six compare trials per brain ran the plain route (routeStage
  none), so web_search never took them. Cork small talk and the kettle how-to went through the picker
  on both brains.
- **Lil thinks on every compare prompt.** About 4k thought chars and ~1,300 decode tokens each, so a
  Lil compare answer takes ~17 s; its other format answers take 2–6 s. Big averages ~8–9 s on compare
  prompts.
- **There is no master baseline for `format`.** The kind doesn't exist on master, so 14/16 and 15/16
  are absolute numbers, not deltas.

**Verdict:** passes on both brains (Lil 6/8 fixtures clean, Big 7/8), with one over-shape on Big.
